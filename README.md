# Hamam 31

Сайт бани Hamam 31.

- `index.html` — страница для гостей: статус пара в реальном времени, расписание, магазин, правила.
- `admin.html` — панель для персонала: вход по логину и паролю, отметки обновления пара, управление администраторами.

Данные хранятся в Firebase (Firestore + Authentication). Настройки проекта — в `js/config.js`,
правила доступа — в `firestore.rules` (их нужно вставить в Firebase Console → Firestore → Rules).

Роли:
- **Главный** (`owner`) — отмечает пар и добавляет/удаляет других администраторов.
- **Отмечает пар** (`admin`) — только отмечает обновления пара и меняет объявление.
